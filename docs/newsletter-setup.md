# 免费红海运价邮件周报：Substack 接入与发送

## 网站与刊物的分工

- 刊物首页：https://redsearate.substack.com/ 。公开订阅页：https://redsearate.substack.com/subscribe 。
- 首页、运价页、周报归档及每期正文后都有中英文订阅入口，沿用现有 teal 样式。只有点击后才前往 Substack；本站不嵌入第三方脚本、表单或追踪像素，不保存订阅邮箱。
- **目前是一个英文刊物。中英文网站入口都订阅同一份英文周报**，中文入口已明示。中文网页仍可正常阅读，不代表开通了独立中文邮件。切换网站语言不会改变邮件偏好。
- Notion 仍管理已审核的站内正文，价格与网页周报生成流程保持不动。**生成网页不等于发送邮件**，也不会自动同步 Substack 文章；第一版由人审核后在 Substack 发送。

## 已配置的公开链接

`data/newsletter.json` 中的 `en`、`zh` 均已配置为 `https://redsearate.substack.com/subscribe`。这些是公开链接，不是密钥，**不需要密码、API key、GitHub secret 或新 workflow**。

- `lib/newsletter.ts` 只接受本刊 HTTPS `/subscribe` 地址，不接受后台、其他刊物、重定向参数或带凭据的链接。
- 将某个入口设为 `null` 可暂停该语言网站的订阅按钮，并保留在线周报链接；不会回退到另一个入口。改配置后需要重新构建部署。
- 本地检查：`npm test`、`npm run typecheck`、`npm run build`。用户在 Cursor 自行提交后，现有部署发布新入口。
- 暂停网站入口不会暂停 Substack 发送，也不会删除既有订阅者。名单与发送设置需在平台内分别管理。

## 用户在 Substack 还需要核对

1. 保持免费订阅，不开启付费墙。核对刊物名称、简介、头图、真实运营及发件人信息、有人处理的回复渠道和平台要求的页脚资料。无需为本次链接接入改 DNS；只有主动启用自定义域名或邮件域名时才按平台实际要求处理。
2. 在 About、欢迎邮件或可用的订阅说明位置说明每周发送市场简报，包含运价及询价链接，读者可随时退订。链接本站隐私页 `https://redsearate.com/privacy/`、`https://redsearate.com/zh/privacy/` 和 [Substack 隐私政策](https://substack.com/privacy)。
3. Substack 位于美国，使用美国及其他国家的服务商。实际运营者需核对中国境外处理订阅资料的告知、同意及适用义务。使用平台不等于自动满足合规要求，不导入未经同意的询价邮箱，不购买名单。
4. 用自己控制的邮箱完整订阅一次，按实际页面或邮件提示验证，确认名单状态。未核实账户设置前，不承诺每个人都会经过相同的二次确认流程。
5. 检查欢迎邮件、平台推荐、通知和追踪选项，关闭不需要的设置。本文只承诺一份每周编辑简报，不承诺平台绝不发送验证或账户邮件。
6. 先发测试邮件，检查手机排版、回复渠道、运价原文链接和退订。用 QQ/163 及 Gmail/Outlook 等真实邮箱、国内网络分别测试访问和投递，不预设一定可达。

## 每周发送流程

1. 现有周报 workflow 计划每周一 02:00 UTC（北京时间 10:00）生成站内新一期，GitHub 定时任务可能延迟。网站每 10 分钟重建不应触发邮件群发。
2. 打开本周 `/market-brief/YYYY-MM-DD/`，核对期数、数据截至日期、40HQ 口径、近 28 天窗口、样本量及环比。**上期距本期超过 7 天时，不把“自上期变化”写成“周环比”。**
3. 没有新数据、数据陈旧或样本不足时说明缺口或暂缓发送，不用估算补缺，不拿旧数字包装成新更新。
4. 在 Substack 建立草稿，复制站内真实数值与已审核叙述。Muse AI 可协助起草，但人审后才发送；不编船期、可订价格、舱位情况或涨跌预测。
5. 结构：一句摘要 → 五港数据 → 出运提示 → 完整周报和询价入口 → 数据口径与退订。保留“市场参考，不是可直接订舱的报价”的边界。
6. 先向自有邮箱发送预览，再由人确认通过邮件发布，每期只发送一次。不因修改网页或文章小错重复群发。

### 英文邮件结构

- Subject: `Red Sea freight brief | ` 后接当期日期和一项核实过的市场变化。
- Preheader: `40HQ market medians, weekly moves and quote counts across five ports.`
- Lead: 从本站本期英文摘要摘取，不夸大成预测。
- 五港表：Destination / 40HQ median (USD/container) / Week on week / Quotes。
- Reminder: `Market references, not bookable offers. Based on 28-day quote medians; sample changes can affect the weekly move.`
- CTA: `Read the full brief` 指向当期英文网页；`Shipping soon? Ask for a current quote` 指向 `https://redsearate.com/#estimate`。

### 将来开通中文邮件时

需要先在 Substack 配好中文 Section 或独立刊物，并实测订阅偏好。不能只加一个带语言参数的链接就声称已经分组，也不能把现有英文订阅者默认加进中文邮件。完成后再修改网站配置、链接校验、按钮和隐私说明。

可复用的中文邮件结构：

- 主题：`红海运价周报｜` 后接当期日期和一项核实过的变化。
- 导语：从本站当期中文摘要摘取，不将短期波动写成确定趋势。
- 五港表：目的港 / 40HQ 中位数（美元/柜）/ 周环比 / 报价样本。
- 提醒：`数据取近 28 天市场报价中位数，不是可直接订舱的报价；样本构成变化也会影响周环比。`
- CTA：`查看本期完整周报` 指向当期中文网页；询价入口 `https://redsearate.com/zh/#estimate`。

## 验收与边界

- 检查中英文首页、运价页、周报归档和当期页：按钮均指向本刊订阅页，中文明确邮件语言；未点击前不请求 Substack。
- 自有邮箱实测：订阅 → 按提示验证 → 出现在本刊名单 → 测试周报 → 回复 → 退订。检查重复订阅、错误邮箱、退订后重新订阅；不手工绕过退订意愿。
- 本次接入只使用公开刊物 URL，不登录用户后台，不提交邮箱、不发送文章或测试邮件，也不修改平台设置。网站代码验证通过不等于真实投递已验证。
- 前四期重点看有效订阅、退订、真实回复和询价，不只追求邮箱数量。Substack 访问失败时，读者仍可在本站阅读周报。
