# Grokbot 价格录入与维护说明

网站价格库是唯一的价格来源。Grokbot 负责：收价、原文存档、整理入库、保持服务器在线、每日备份。

```
同事/老笠的微信消息 ──▶ Grokbot ──▶ 1. 原文存档 inbox/
                               ──▶ 2. 整理成 CSV，POST /api/prices（网站立即更新）
                               ──▶ 3. 每 20 分钟访问网站，保持在线
每天 23:15 ──▶ scripts/backup-prices.sh ──▶ 私有仓库 KarmaKong/redsearate-prices
```

## 1. 原文存档

每收到一条价格消息，把原文追加到价格仓库的 `inbox/YYYY-MM-DD.md`（上海日期）：

```markdown
## 14:32 同事B

上海-吉达 40HQ 7800，11/6前有效，含BAF，CMA
```

原文只追加，不修改。整理出错时以原文为准重新整理。

## 2. 整理成 CSV

每条价格一行，列顺序固定，第一行表头可有可无（中英文均可）：

```csv
日期,类型,起运港,目的港,柜型,价格USD,有效期,航程最短,航程最长,来源,录入人,备注
2026-10-23,市场价,上海,吉达,40HC,7800,2026-11-06,28,32,CMA,同事B,含BAF
```

| 列      | 规则                                                                                                                            |
| ------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 日期    | 收到报价的日期 `YYYY-MM-DD`，留空为今天，不能晚于今天                                                                           |
| 类型    | 团队收集的价格和公开网页价格都填 `市场价`（留空也按市场价）。`本站报价` 只用于我们承诺可订、愿意公开的价格；`内部底价` 永不公开 |
| 起运港  | 上海 / 宁波 / 深圳 / 青岛（也可写 Shanghai、CNSHA 等英文名或代码）                                                              |
| 目的港  | 吉达 / 苏赫纳 / 亚喀巴 / 苏丹港                                                                                                 |
| 柜型    | `20GP` `40GP` `40HC` `LCL`；40HQ 会自动按 `40HC` 处理                                                                           |
| 价格USD | 港到港纯海运，美元。整柜按每柜，拼箱按每 W/M（每立方或每吨取大）                                                                |
| 有效期  | `YYYY-MM-DD`，如「11/6 前」写 `2026-11-06`；留空则按日期后 7 天，并自动在备注注明                                               |
| 航程    | 天数，可留空                                                                                                                    |
| 来源    | 船公司、同行或网站名，只在内部可见                                                                                              |
| 录入人  | 最初发出这条价格的人                                                                                                            |
| 备注    | 口径说明，如含/不含 BAF、THC；含逗号时整格加英文双引号                                                                          |

不导入的情况：非美元价格、门到门或含目的港费用/清关的价格（口径不同，会拉偏中位数）、不在上面列表里的港口。这些只留在原文存档里。

## 3. 提交

```sh
curl -sS -X POST https://redsearate.com/api/prices \
  -H "Authorization: Bearer $PRICE_API_KEY" \
  -H "Content-Type: text/csv" \
  --data-binary @today.csv
```

返回 `{"added":5,"duplicates":1,"errors":[{"line":3,"error":"起运港不支持：厦门"}]}`：

- 有效行直接入库，出错的行按行号报告，不影响其他行。
- 日期、类型、航线、柜型、价格、有效期、来源、录入人都相同的行视为重复并跳过，所以修正错误后可以把整批重新提交。
- 401 表示密钥不对。`PRICE_API_KEY` 只放在服务器环境变量里，不要发在聊天中。

网站规则：同一航线和柜型满 5 条近 28 天的有效市场价后，才公开显示中位数；单条价格、来源、录入人都不会公开。录入结果可在 `/pool` 查看和删除。

## 4. 保持在线（instabox）

instabox 机器空闲 30 分钟会自动暂停，访问公网地址会把它唤醒。Grokbot 每 20 分钟访问一次：

```sh
curl -fsS -o /dev/null https://redsearate.com/robots.txt
```

上线后实测一次：持续访问 40 分钟以上，用 `instabox list` 确认机器一直是 running。手动暂停或停止的机器不会被访问唤醒。

## 5. 每日备份

服务器上克隆私有仓库 `KarmaKong/redsearate-prices`（用该仓库的 deploy key，勾选写权限），inbox 原文也写在这个目录里，然后加 cron：

```sh
15 23 * * * SITE_URL=http://localhost:3000 PRICE_API_KEY=... /srv/redsearate/scripts/backup-prices.sh /data/redsearate-prices
```

脚本导出全部价格为 `prices.csv`，连同 `inbox/` 一起提交并推送。需要恢复时，把 `prices.csv` 原样 POST 到 `/api/prices` 即可（重复行会跳过，日期保留）。
